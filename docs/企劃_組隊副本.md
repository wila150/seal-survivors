# 企劃：組隊打副本（連線共同遊玩）（v1.1，2026/11/20 使用者已決定）

> 使用者 11/20：「有辦法做到之後一起組隊打副本嗎？」→「遠征那些還有連線共同遊玩那些企劃呢？」→「寫組隊企劃」
> 前提：11/20 雲端帳號已上線（Cloudflare Workers＋Durable Object，見 企劃_工程交付「雲端帳號」），手機電腦同一個帳號。
> 原本 企劃_工程交付 寫「組隊（最多 3 人、Need/Greed 擲骰、共享 EXP）先不做」，這份取代那一行。
> 標 🔢 的數值是暫定，玩了再調。標 ❓ 的是要使用者決定的。

## 0. 目標
- 2～3 個人（❓ 人數）同一張地圖、同一批怪，一起打到 15 分鐘首領通關
- 手機、電腦可以混著組
- 費用維持 0 元（Cloudflare 免費額度內，算法見第 8 節）
- 單人玩法完全不變：沒組隊就跟現在一樣

## 1. 大廳：隊伍視窗（照 PC 組隊介面）
主城底部選單加「隊伍」按鈕（PC 是社交選單 → 隊伍），獨立一個視窗，不跳到別的視窗：

| 動作 | 說明 |
|---|---|
| 建立隊伍 | 自己當隊長，產生 6 碼隊伍代碼（例：`K7P2QX`）＋邀請連結 |
| 加入隊伍 | 輸入代碼，或點隊友傳來的連結（LINE 傳給朋友直接點） |
| 隊員列表 | 頭像、名字、職業、Base Lv、戰鬥力、「準備好了」勾勾 |
| 隊長操作 | 選地圖＋難度（沿用現在的「難度」視窗）、踢人、轉讓隊長、出發 |
| 隊員操作 | 準備／取消準備、離開隊伍 |
| 出發 | 全員勾準備才能按；所有人同時進入同一局 |

- 不做：好友名單、頻道、公開房間列表（先用代碼／連結找人）❓
- 閒置 5 分鐘沒動作自動離開隊伍（使用者 11/20 截圖：RO Survivors 也是這樣），回大廳顯示「你已閒置 5 分鐘，離開了隊伍」

## 2. 局內玩法（跟單人的差別）
| 項目 | 規則 |
|---|---|
| 怪物 | 全隊同一批怪；數量 ×(1＋0.5×(人數−1))、血量 ×(1＋0.6×(人數−1)) 🔢 |
| 首領／MVP | 同一隻，血量 ×人數 🔢；照現在 5／10／15 分出場 |
| 經驗寶石 | 誰撿到算誰的；另外每顆寶石，附近 15 公尺內的隊友也拿 50% 🔢（PC 組隊經驗分享的味道） |
| 金幣 | 各撿各的 |
| 升級選卡 | ❓ 見第 7 節決定 1 |
| 連續技、技能 | 各自的，照現在 |
| 隊友倒下 | 不直接結束：倒地 30 秒內，隊友站在旁邊 3 秒把他扶起來（回 30% HP）；30 秒沒人救就變觀戰 🔢 |
| 結束 | MVP 打倒＝全隊通關；全隊都倒下或時間到＝結束 |
| 畫面 | 隊友頭上名牌＋小血條；小地圖顯示隊友位置；左上隊伍列表（名字、HP） |
| 暫停 | 組隊不能暫停（Esc 只開設定）；「回主城（保留這一局）」組隊時不能用 |

## 3. 掉落：Need／Greed 擲骰（照 PC 組隊分配）
- 寶箱裡的裝備跳出擲骰視窗給全隊：「需要」（本職業可穿才能按）／「貪婪」／「放棄」，15 秒內選 🔢
- 先比「需要」的人擲 1～100，沒人需要再比「貪婪」；全放棄 → 開寶箱的人拿
- 材料、寶石、礦石：各自的寶箱各自拿，不擲骰
- 結算畫面列出這局每件裝備誰擲到

## 4. 結算
- 每個人照自己的擊殺、時間、等級，各自送現在的結算（/api/runs，多帶 party 欄位：隊伍代碼、人數）
- 組隊加成：經驗 ＋10%×(人數−1) 🔢（鼓勵組隊）
- 排行榜：維持個人；另加「組隊通關」分頁 ❓

## 5. 連線怎麼做（技術）
- 每支隊伍＝Cloudflare 一個 Durable Object 房間，瀏覽器用 WebSocket 連進去（現在帳號用的同一個 Cloudflare Worker）
- **隊長的瀏覽器當主機**：怪物、首領、寶箱、掉落都由隊長算，每秒送 10 次給隊員（位置用內插，看起來是順的）
- 隊員只送自己的：位置、面向、放了什麼技能、打中哪隻怪多少傷害（隊長收到再扣血）
- 房間伺服器只做轉送＋檢查（不是這隊的人進不來、傷害數字合不合理），所以很省
- Durable Object 用「休眠 WebSocket」：沒有訊息時不算時間，費用最低
- 斷線：
  - 隊員斷線 60 秒內重開網頁會自動回到這一局（位置、等級、技能留著）🔢
  - 隊長斷線：自動換延遲最低的隊員當主機繼續 ❓（做起來多 2～3 天；不做的話＝這局結束，各自結算已拿到的）
- 延遲：台灣↔Cloudflare 一般 20～60 毫秒；手機 4G 可以玩

## 7. 需要使用者決定 ❓
1. **升級選卡**：A. 不暫停，卡片顯示在畫面上方，10 秒內按 1／2／3 選，沒選自動選第 1 張（建議）／B. 有人升級全隊暫停等他選（單人手感，但 3 個人會一直停）
2. **人數上限**：3 人（企劃原本寫的，建議）／4 人／PC 原版 8 人（怪會太多，手機會卡）
3. **隊長斷線**：A. 換人接手繼續（多 2～3 天）／B. 這局結束、各自結算（建議先做 B，之後再補 A）
4. **找隊友**：只用代碼＋連結（建議）／另外做公開房間列表
5. **賢者之塔 Another 要不要改成一定要組隊**（照官方 wiki）
6. **排行榜要不要加「組隊通關」分頁**
7. 第 2～4 節標 🔢 的數值先照表做，玩了再調？

## 7.1 v1.1 使用者決定（11/20）
> 原話：「我們就照著建議做／組隊 3～4 個吧／然後用代碼進入或是好友邀請／越多人組隊怪越痛／有人升級 A」
1. 升級選卡：**A**（不暫停，10 秒內選，沒選自動選第 1 張）
2. 人數上限：**4 人**
3. 隊長斷線：照建議 **B**（這局結束、各自結算已拿到的；換人接手之後再補）
4. 找隊友：**代碼／連結＋好友邀請**（新增好友系統，見 1.1）
5. 賢者之塔：照建議先維持可單人進（組隊也能進），之後再看要不要改成一定要組隊
6. 排行榜「組隊通關」分頁：照建議做（階段七）
7. 🔢 數值照表；另外「越多人怪越痛」：怪物攻擊 ×(1＋0.25×(人數−1)) 🔢（4 人＝×1.75）

## 1.1 好友（v1.1 新增，照 PC 社交選單的好友名單）
- 「隊伍」視窗旁邊加「好友」分頁：輸入角色名稱加好友（對方不用同意，PC 是單向名單）🔢、刪除好友
- 好友列表顯示：名字、職業、Base Lv、在不在線上（最近 2 分鐘有動作＝在線）
- 有隊伍時，好友旁邊有「邀請」按鈕 → 對方在主城跳出「○○ 邀請你加入隊伍：加入／拒絕」（主城每 20 秒檢查一次邀請，分頁沒開著就不檢查，省額度）
- 邀請 5 分鐘沒回就失效

## 8. 費用（Cloudflare 免費方案）
- 一場 3 人 15 分鐘：隊長每秒送 10 次 × 2 個隊員 ＋ 隊員每秒送 10 次 → 約 4 萬則訊息
- 休眠 WebSocket 每 20 則訊息算 1 次請求 → 約 2,000 次請求／場
- 免費額度每天 10 萬次 → 每天約 **50 場**組隊都不用錢；超過當天會被擋，不會自動扣款（要升級每月 5 美元方案才會收費）
- 以上照 Cloudflare 公布的免費方案，開始做之前再確認一次
