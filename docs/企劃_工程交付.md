## 0. 先讀這三條
1. **只要割草**：玩法像《RO 倖存者》——自動攻擊、走位、升級三選一、打王。不做 MMO 式手動施法。
2. **PC 做什麼樣子就做什麼樣**：模型、動作、技能名稱、技能圖示、屬性都用《希望 Online》PC 版原版。
3. **角色技能以職業定**：每個職業只會出自己職業的招式，升級卡片不會出現別職業的技能。

### 版權（一定要遵守）
- 希望 OL 素材（模型、貼圖、音效、音樂、技能圖示）**只限本機測試**，不部署、不推公開 repo、不放到任何公開網址。
- 正式上線用的素材要向研發方取得授權版本；不破解客戶端加密檔（.SPAK）。
- 交接時素材另外用隨身碟／私人雲端給，不進 git。

## 二、核心模組規格

### 1. 玩家控制（player.js）
- 移動只算 **XZ 平面**；碰撞、技能範圍也都只算 XZ 距離（**不要用 3D 距離**——投射物在半空、怪在地上，算進高度會打不到，這個 bug 已經修過一次）
- 電腦：WASD／方向鍵；手機：按住畫面任意處拖曳 = 浮動搖桿
- 角色面向移動方向；出招時轉向目標
- 磁吸經驗寶石：範圍 `P.magnet`（基礎 2.5，「磁力」被動 +40%）
- 受傷後 0.5 秒無敵、模型閃爍
- 騎乘坐騎：按 R 或按鈕切換，移速 +15%、**不能攻擊**，切換冷卻 2 秒

### 2. 攝影機（camera.js）
- 45 度斜角俯視，跟著玩家；主城鏡頭高 21、後退 18；出征依直／橫螢幕調整高度與距離（game.js 現有邏輯）
- 首領登場時鏡頭震動（bossFx.shake）

### 3. 物件池（pool.js）
- 怪物、投射物、特效、經驗寶石、傷害數字**全部回收重用**，戰鬥中不准一直 new／dispose
- 特效池已經有 `FxPool`（skills.js），照它的介面擴充到其他物件：`get()`／`release()`／`update(dt)`／`clear()`
- 同屏上限：怪物 200、傷害數字 40、特效 300

### 4. 遊戲流程（game-manager.js）
- 一局 **10 分鐘**；首領時間表在 stages.js：2、4、6、8 分小王，10 分 MVP，打倒 MVP 通關
- 生怪：每秒 1.2 隻起跳，越久越多，上限每秒 11 隻；每 45 秒一隻精英（40% 掉寶箱）
- 怪物跑太遠（>45）拉回玩家附近
- 結算只在局末送伺服器（`POST /api/runs`）：秒數、擊殺、局內等級、是否通關、寶箱數、地圖。伺服器自己擲裝備、算經驗與金幣（防作弊）
- 切到背景就暫停、停止繪圖（不常駐）

### 5. 自動技能（skills.js — 已完成，接手時維持）
詳細見 `企劃_技能系統.md`。重點：
- 資料驅動：`assets/data/skills.json`，第 l 級數值 = `base + per × (l − 1)`
- 四種類型：`MELEE_ARC` 扇形近戰、`PROJECTILE_BOUNCE` 彈射投射物、`ORBIT_AURA` 環繞光環、`ZONE_AOE` 區域轟炸
- 自動索敵：找最近（或範圍內隨機）敵人施放，冷卻 × `P.haste`
- 屬性聯動：冰 → 緩速；緩速／暈眩中的怪被火或重擊打到 → 必定爆擊 ×1.5（顯示「碎冰！」）；首領只吃一半緩速、不會被暈
- 超武：兩招 Lv5 → 金色融合卡 → 取代兩招，換成 PC 版二轉技能
- Combo：每次命中 +1，3 秒沒打到就斷；每 50 連擊放一次職業無雙（最快 6 秒一次）

## 三、自我偵測（對照骨架的 SealAutoBuilder3D／RuntimeWatchdog3D）

### 1. 一鍵素材體檢：`node tools/asset-check.mjs`（新做）
跑一次就把所有會讓遊戲壞掉的素材問題列出來，有錯誤時 exit code ≠ 0。

| 檢查 | 判定 |
|---|---|
| 模型 JSON 都讀得到、每個部位有頂點和面 | 錯誤 |
| 模型高度（原始單位）異常：玩家 < 0.5 或 > 3、怪物 < 0.05 或 > 50 | 警告（可能比例錯） |
| 貼圖 PNG 檔存在 | 錯誤 |
| 玩家模型：蒙皮部位每個頂點都有權重、權重加總 ≈ 1、骨頭編號 < 骨頭數 | 錯誤 |
| `anims/sets.json`：12 組（6 職 × 男女）都有 pi／rn／f1／f2／f3／dd，而且動作檔存在 | 錯誤（缺動作 = 定住或滑步） |
| `skills.json`：每職業 pool 剛好 4 招、start 在 pool 裡、fusion 的 a／b／into 都存在、圖示座標在圖檔範圍內、fx key 都有對應圖 | 錯誤 |
| `stages.js` 的每隻怪與首領都在 monsters.js 有對應模型 | 錯誤 |
| 艾林主城用到的 25 種模型都存在 | 錯誤 |

輸出範例：`=== 素材體檢 === 模型 1820 / 動作 73 / 技能 30　錯誤 0　警告 3`

### 2. 執行時看門狗：`src/4_diagnostics/watchdog.js`（新做）
網址加 `?debug=1` 才顯示面板；沒加也會把問題寫進 console。
- **掉幀**：連續 3 秒低於 45 fps → 警告，附上當下怪物數、特效數、draw calls（`renderer.info.render.calls`）
- **物件洩漏**：每 10 秒記錄 `scene.children` 數量、各物件池使用量；連續 3 次只增不減 → 警告是哪一類
- **穿模／跑出地圖**：玩家或怪物座標變 NaN、y < −1、玩家跑出主城邊界 → 錯誤並把位置拉回
- **模型載入失敗**：sealModel／sealActor reject 時顯示模型名（不要靜默吞掉）
- **動作卡住**：玩家在移動但動作不是 rn 超過 1 秒 → 警告
