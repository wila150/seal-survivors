# 企劃：希望OL 倖存者 總體架構 v0.1

參考對象：別人做的「RO 倖存者」（帳號 → 角色欄位 → 主城大廳 → 出征刷怪）。
我們只學它的**結構**，內容全部換成希望OL的：怪物、職業、地圖、音樂都用希望的，不放任何 RO 的東西。

## 流程
登入／註冊 → 角色選擇（15 格）→ 建立角色（名稱、性別、職業、服裝顏色、素質）→ 主城大廳（NPC）→ 出征（倖存者局）→ 結算帶回經驗 → 回主城

## 1. 局內戰鬥（已有原型，見 企劃_核心玩法.md）
- 怪物改用希望的，照 monster.scr 等級排出場：咕咕 → 小豌豆 → 整人箱 → 蘑菇弟弟 → 飛天豬 → 熊家族 → 骷髏兵 → 泰坦
- 每 60 秒出一隻精英怪，每關最後出一隻首領（例如菜頭王、骷髏王、魔蠍大帝）
- 升級三選一：強化技能或拿被動能力

## 2. 局外成長
- 角色素質配點：先用 力量／智力／體力／敏捷／運氣 五項（伺服器資料查不到原版素質名，**待確認**是否照希望OL原版改）
  - 建立角色：每項基礎 1，自由 20 點，單項上限 15；定義在 jobs.js
- 職業：建立角色時直接選一轉職業（使用者 11/18 要求），之後再二轉
  - 一轉（從 item.txt「XX專用」查到）：劍士（劍氣斬）、騎士（衝擊波）、法師（雷擊）、祭司（聖光環＋回血）、小丑（飛彈）、鐵匠（鐵鎚重擊）
  - 二轉資料裡出現：魔劍士、聖騎士、刺客、弓箭手、俠客、吟遊詩人、舞者、藝者、匠師、大祭司、貴族 — **待確認**哪個一轉接哪個二轉
- 各職業各有一組局內技能

## 3. 裝備
- 出征掉落武器和防具（圖示用 GM 工具那 6145 張）
- 強化：沿用希望OL的強化系統，有失敗風險。**待確認**規則

## 4. 主城大廳 NPC
出征隊長（進出征）、排行榜（最久存活）已可用；轉職官、裝備商人、強化師、倉庫先有對話，功能待後面階段
- 結算經驗 = 存活秒數/3 + 擊殺/4 + 局內等級×5；角色升級需求 60×Lv×1.15^(Lv-1)

## 5. 多人與交易（最後做）
需要伺服器，而且會牽涉上線（版權）。**待確認**是否做、做給誰玩。

## 技術
- 前端 Three.js（3D），手機＋電腦瀏覽器
- 伺服器：本機 Node（server.mjs）＋ SQLite（data/game.db），帳號密碼用 scrypt 雜湊（使用者 11/18 選「現在就做伺服器帳號」）
- 啟動：`node server.mjs` → http://localhost:8765
- 希望OL素材只限本機，不部署
