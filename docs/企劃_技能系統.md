# 企劃：職業技能系統 v1.0（使用者 2026-11-18）

需求來源：使用者 11/18 指定（資料驅動技能表、四種技能類型、屬性聯動、二轉超武、Combo 無雙、三選一 UI），
並要求「**依照自己的職業放出自己的招式**」：升級卡片只出自己職業的技能，不會出現別職業的招式。
職業基礎技能名稱沿用現狀（docs/參考_開發總綱.md 只當參考）。

## 1. 架構
- `assets/data/skills.json`：技能配置表（名稱、職業、類型、屬性、圖示、每級數值、超武條件）
- `skills.js`：SkillManager（依類型執行技能、屬性狀態、超武融合、Combo、物件池特效）
- 數值公式：第 l 級數值 = `base + per × (l − 1)`，Lv 1～5

## 2. 四種技能類型
| 類型 | 行為 |
|---|---|
| MELEE_ARC 扇形近戰 | 朝最近敵人（沒有就朝面向）揮出扇形，範圍 range、角度 arc |
| PROJECTILE_BOUNCE 彈射投射物 | 朝最近敵人射出 count 發；命中後彈到下一隻（bounce 次）或穿透（pierce） |
| ORBIT_AURA 環繞光環 | count 個物件繞身旋轉，每 0.25 秒對碰到的怪造成傷害 |
| ZONE_AOE 區域轟炸 | 在目標點（最近敵人／自己腳下／隨機敵人）產生 count 個範圍傷害 |

## 3. 屬性聯動
- **冰（ice）**：命中附加緩速 2 秒（移速 −40%），怪身上變藍
- **火（fire）／重擊（heavy）**：打中「緩速中」的怪 → 必定爆擊，並額外 +50% 傷害（顯示「碎冰！」）
- 每個職業至少有一招冰、一招火或重擊，讓自己職業內就能打出聯動

## 4. 各職業技能 v1.1（11/18 使用者：「PC 做什麼樣子就做什麼樣，但只要割草，像 RO 倖存者」）

超武 = 兩招 Lv5 融合成 PC 版二轉技能；無雙 = 該職業 PC 版最高階技能。數值是割草版自訂（約 PC 傷害% ÷ 35）。

| 職業 | 開局 | 其他三招 | 超武（兩招 Lv5） | 無雙（每 50 連擊） |
|---|---|---|---|---|
| 劍士 | 流雲斬（扇形・重擊） | 旋風斬（環繞・緩速）、疾風斬（彈射）、光速斬（落點・重擊） | 流雲斬＋疾風斬 → 劍舞 | 異界斬 |
| 騎士 | 十字攻擊（腳下・重擊） | 八方攻擊（360°・緩速）、盾牌投擲（彈射 3 次）、十字神劍（落點・重擊） | 十字攻擊＋八方攻擊 → 神撼大地 | 天罰 |
| 小丑 | 任意投擲（投射穿透） | 隨意投擲（卡片彈射・重擊）、毒匕首（中毒）、催眠曲（環繞・緩速） | 任意投擲＋隨意投擲 → 天女散花 | 停止動作 |
| 法師 | 冰劍術（彈射・冰） | 火風暴（落點・火）、冰柱術（落點・冰）、火精靈（環繞・火） | 冰劍術＋冰柱術 → 寒冰炮彈術 | 冰冷疾風 |
| 祭司 | 譴責（扇形・重擊） | 聖光（落點）、審判之力（腳下・緩速 50%，原版效果）、天譴（落點・重擊） | 譴責＋審判之力 → 審判 | 聖域 |
| 鐵匠 | 致命一擊（扇形・重擊） | 投擲炸彈（落點・火）、多重粉碎（腳下・緩速）、一擊毀滅（暈眩機率，原版 20%） | 致命一擊＋投擲炸彈 → 全面毀滅 | 飛天槌擊 |

- 技能圖示：PC 版圖示表（assets/skill/skill1.png、skill3.png，來自 2u 資料站）
- 無雙最快 6 秒一次（太密會蓋掉其他技能）；首領吃一半緩速、不會被暈

## 4.5 普攻 v1.2（11/18 使用者：「遊戲開始應該先用普攻，再來選第一個技能」）
- 開局只有普攻（PC 版武器技能名稱）：劍士 雙手劍技、騎士 單手劍技、小丑 匕首技（投擲）、法師 持杖技（魔法彈）、祭司 鎚技、鐵匠 鐵槌技
- 第一次升級只出 3 張技能卡，選第一招；之後普攻也會出現在卡片裡，可升到 Lv5（不參與超武融合）
- 底部技能列照 RO 倖存者：普攻大格＋4 格技能（空格顯示＋），上面一排 5 個小格是被動

## 5. Combo 連段（**11/18 取消**：使用者「不要有連擊 Buff，之後怪多隨隨便便都能達成」。連擊條、無雙都拿掉，skills.json combo.enabled=false，程式保留不呼叫）
- 每次命中 +1；3 秒沒命中就斷連（畫面上方連擊數＋倒數條）
- 每滿 50 連擊自動放一次「職業無雙」：以自己為中心的大範圍傷害（顏色依職業）
- 結算記錄本局最高連擊（之後做稱號，見總體架構階段七）

## 6. 特效
- 技能特效、投射物、拖尾粒子都用物件池（不在戰鬥中一直建立／銷毀）
- 投射物有粒子拖尾；扇形、轟炸、無雙用地面特效＋光柱

## 7. 三選一 UI
- 卡片顯示：技能名稱、類型與屬性、Lv a → b、數值變化（傷害 14 → 20 這種）
- 超武條件提示；滿足時出現超武卡

## 5. v1.2 冷卻照 PC 原始數值（11/20 使用者：「抓得到他的技能冷卻時間嗎？用 PC 最初始的數值不要去改動」）
- 來源＝2u 資料站 info-table.php 的「冷卻時間」（各等級）；跟服務端 skill01～20.scr 第 18 欄大致一樣，不同的（劍舞 8／6、寒冰氣旋 3.5／1）以 2u 為準
- skills.json：base.cd＝PC Lv1 冷卻、拿掉 per.cd（PC 每級冷卻不變）；每級會變的 5 招（纏繞樹根、完美冰封術、冰冷疾風、飛天槌擊、火力集中）存 pcCd 陣列，stat() 依等級取
- 不改的：PC 冷卻 0 的（普攻 6 招、任意投擲、隨意投擲、投擲炸彈、奮力投擲、制鏈專家）＝PC 靠攻擊速度，自動施放不能 0 秒 → 維持原本割草版數值；環繞／光環類（旋風斬、火精靈、聖域…）本來就沒有冷卻；初心者自訂招（丟石頭等）PC 沒有
- 局內冷卻縮短（卡片、技能寶石、天賦、裝備）照舊乘在 PC 冷卻上
