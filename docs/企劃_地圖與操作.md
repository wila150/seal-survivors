# 企劃：地圖、操作與登入畫面 v1.0（使用者 2026-11-18）

參考：RO 倖存者（使用者截圖＋描述）。只學結構，內容換成希望OL。

## 1. 操作
- 電腦：WASD／方向鍵；**滑鼠左鍵點地面移動**（按住會一直跟著滑鼠走，點擊處顯示小光圈）；按鍵盤會取消點擊移動
- 手機：按住畫面拖曳 = 浮動搖桿（不變）
- **切換視角**：V 鍵或右下 🎥 按鈕，斜角 → 遠景 → 3D 低角度；滑鼠滾輪縮放；記住上次選的視角

## 2. 角色動作
- 移動中不播全身攻擊動作（不然腳停住、看起來在原地卡頓）；站著才播攻擊
- 站／跑切換有緩衝，搖桿小抖動不會一直重播
- 跑步動作速度跟移動速度連動
- 手上拿原版武器：劍士大劍 R_Bgaa、騎士劍＋盾 R_Saa／L_Sac、法師法杖 R_Stac、祭司鎚 R_Mcac、小丑匕首 R_Ssaa、鐵匠鐵鎚 R_Bwaa（女角自動換算到女角骨架）
- 修正抽搐（11/18 使用者錄影，每 0.1 秒抽格看到面向來回跳）：改成平滑轉身（最快每秒 12 弧度）；移動中只面向移動方向，站著出招才轉向目標；攻擊動作最快 0.9 秒一次。主城也改平滑轉身
- 修正：部分原版動作檔骨頭名是小寫（騎士劍盾），以前對不上骨架所以不會動

## 3. 區域地圖 v1.1 [已完成 11/18]
使用者：「什麼怪物在什麼區域，做一張地圖，會有王」
- 每張遠征地圖改成一張大地圖，分成幾個區域，每區出不同怪、區域中心有該區的王
- 小地圖顯示區域與王的位置
- 需要決定：區域數量、每區的怪與王（照 stages.js 現有怪物分配）、地圖大小與邊界、走進區域才生該區的怪還是全圖照時間生

- 操作：左鍵點地移動、**右鍵（或中鍵）拖曳：左右轉向、上下調俯角**、Q／E 鍵轉向、滾輪縮放（主城、遠征都一樣）
- 游標：客戶端原版 resource/cursor1.tex 切成 assets/ui/cursor_*.png（arrow／attack／talk／pick／no），三個頁面都用 arrow
- 11/18 修「人物一直抽動」：①動作長度改用最後一個關鍵格（原版檔頭長度較長，例：跑步關鍵格 0.8 秒、檔頭 1 秒 → 每圈停 0.2 秒再跳）②循環動作最後一格設成跟第一格相同（騎士待機左手會跳）③站姿改用原版 w1（安靜站著；原版 pi 是戰鬥備戰、一直彈跳），使用者 11/18：「不用一直動來動去，過一段時間停一下伸懶腰」→ 站著 6～10 秒後播一次原版 w2 等待動作（伸懶腰、東張西望），之後每 8～15 秒一次，移動或攻擊會打斷；逐格量骨頭位移確認 6 職業待機／跑步沒有週期跳動
