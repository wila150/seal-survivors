《希望倖存者 3D》專案開發總綱（企劃 ＋ 技術規格書）


一、 專案核心定位與技術架構

• 遊戲類型：3D 動作 Roguelite 倖存者 ＋ MMORPG 打寶衝裝養成。
• 畫面與視角：全 3D 卡通渲染（Toon Shader / Cel-Shading），45 度斜俯視角，高度還原《希望戀曲》童話畫風與裝備發光特效。
• 雙端運行架構：
	• 客戶端（前端）：採用 3D 網頁引擎（Three.js / Babylon.js） 或 跨平台引擎（Unity / Godot 4），同時相容 PC 鍵盤（WASD）與手機觸控虛擬搖桿。
	• 邏輯演算降維：畫面為全 3D 呈現，但移動、碰撞與技能範圍判定統一在 2D 平面（X、Z 軸）計算，大幅降低運算開銷並無縫沿用現有服務端驗證邏輯。
	• 服務端（後端）：沿用現有《RO倖存者》架構（資料庫、帳號系統、背包、交易與結算驗證），僅將資料表替換為《希望戀曲》專屬數值結構。

二、 遊戲雙循環與核心玩法設計


1. 局內循環（單局 10～15 分鐘割草）

• 自動戰鬥與走位：玩家專注走位躲避彈幕與紅圈預警，所有職業武器與技能依冷卻時間自動鎖定目標施放。
• 三選一進化與超武：擊殺怪物拾取經驗結晶升級，從「主動技能 / 被動光環 / 基礎屬性」三選一；指定主動技與被動技滿級後，融合為 「二轉覺醒超武」。
• 動態波次與時間軸：每 1 分鐘切換怪物潮，第 3、6、9 分鐘刷新菁英頭目（掉落寶箱），第 12 分鐘迎戰關卡守關魔王。

2. 局外循環（長期刷寶與養成）

• 安全結算帶出：參考防作弊機制，單局戰鬥中僅記錄擊殺與時間，通關或陣亡結算時才將戰利品（裝備、寶石、寵物蛋）傳回服務端寫入資料庫。
• MMORPG 深度養成：玩家回大廳整理背包、進行寶石衝裝、裝備 G 化／XG 化鑑定、餵食培養寵物，提升基礎戰力後挑戰更高難度關卡。

五、 3D 資產管線與效能優化規範

• 模型轉檔管線：將 PC 版解包出的 3D 模型、動作骨架與貼圖匯入 Blender，重新連結材質並統一匯出為現代引擎標準的 .glb 格式，掛載帶有黑色外描邊的 Toon Shader。
• 同屏千怪效能優化：
	• 物件池（Object Pooling）：所有 3D 怪物、投射物、經驗球與傷害跳字必須使用物件池回收重用，嚴禁在戰鬥中頻繁建立與銷毀實例。
	• GPU Instancing / VAT：大量同質小怪（如哈比兔海）採用 GPU 實例化渲染或頂點動畫貼圖，確保手機與網頁端同屏數百隻怪物依然流暢。

2. 第二階段：戰鬥系統與職業擴充
	• 實作升級三選一介面、6 大職業技能與超武融合公式、Combo 連段計數條與傷害數字跳字。
3. 第三階段：局外養成與服務端串接
	• 對接現有服務端 API 與資料庫，完成大廳背包、寶石衝裝（+1～+12 發光特效）、寵物餵食進化、防作弊結算發獎。
